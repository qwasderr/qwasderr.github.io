A few things I've built or contributed to.

PetCare App

A mobile application designed to help pet owners manage their animals’ information with ease. The app offers features such as pet profile creation, medical history tracking, and reminders for vaccinations and vet visits, all through a user-friendly and intuitive interface focused on pet care.

  • Technologies: ASP.NET Core Web API, ASP.NET Core Identity, EF Core, PostgreSQL, JWT, Swagger, UML, xUnit
  • GitHub Repository

US Roadworks Knowledge Discovery

A data analysis and machine learning project focused on road construction and closure events across the U.S. The system provides tools for visualizing and analyzing a large-scale dataset (6.2M+ records) through interactive dashboards with KPIs and charts. It also includes models for predicting event severity, duration, and distance using modern machine learning techniques, and discovers association rules between key parameters to support process optimization and informed decision-making.

  • Technologies: Python, Power BI, Regression (Linear, Logistic), XGBoost, Apriori, PCA, K-Means
  • GitHub Repository

Referee Management System

A web application designed to streamline the management of referees and sports competitions. The system provides tools for organizing tournaments, tracking matches, and managing referees' activity and certification status.

  • Technologies: ASP.NET Core MVC, ASP.NET Core Identity, EF Core, MS SQL Server, UML, XUnit
  • GitHub Repository
